# cross-platform-music-analytics

Cross-platform music analytics & achievements aggregator following the Songstats model — monitors 15+ platforms across streaming, social/video, electronic DJ stores, discovery, and airplay, and turns them into a unified global analytics report with velocity analysis.

## Contents
- SKILL.md: the full skill definition
- README.md: this file
- manifest.json: metadata for packaging and submission

## What it does
- Aggregates artist/track data across Spotify, Apple Music, Amazon, Deezer, Tidal, Audiomack, TikTok, YouTube, Instagram, Facebook, X, SoundCloud, Beatport, Traxsource, Shazam, and radio/1001Tracklists
- Groups metrics logically: Streaming, Socials, Electronic Commerce, Discovery
- Computes cross-platform velocity to surface where a track is reacting fastest
- Tracks charts, editorial/playlist placements, DJ support, and career milestones
- Renders standardized global analytics reports
