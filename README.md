# Music Industry Agent Skills

Agent skills for music industry professionals, maintained by gtnorbeat.

## Skills

- `ar-label-manager/` — A&R operations: artist scouting, demo reviews, release planning, roster management, and market analysis.
- `cross-platform-music-analytics/` — Global music analytics & achievements following the Songstats model: streaming, social/video, DJ stores, discovery, and airplay across 15+ platforms, with cross-platform velocity analysis.

## Installing

Each skill is a self-contained package (`SKILL.md` + `README.md` + `manifest.json`). Point your agent at the folder, or submit to the Skills.sh registry.
